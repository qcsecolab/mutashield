# MutaShield-Net

**Paper:** A Hybrid Mutation-Guided Adversarial Evolution Framework for Adaptive Web Intrusion Detection Systems  
**Authors:** Faisal Alhwikem (Qassim University), Syed Mohd Saqib (Mustaqbal University)  
**Funding:** Deanship of Graduate Studies and Scientific Research, Qassim University (QU-APC-2026)

The framework comprises three interdependent components:

**SMOE — Spectral Mutation Operator Engine**  
Generates semantically valid traffic mutations via graph-spectral decomposition of HTTP request-response flows. Registers 28 atomic operators across 7 taxonomic attack families. Semantic preservation is enforced by a score-threshold constraint (δ = 0.8).

**CA-GRT — Cross-Domain Attention-Gated Recurrent Transformer**  
Detection backbone fusing bidirectional GRU temporal encoders with multi-head cross-domain attention over both packet-level and application-layer semantic feature streams. Domain-specific gating combines the two representations.

**AMFEL — Adversarial Mutation Fitness Evolutionary Loop**  
Co-evolutionary optimisation wherein mutation population P_M and detector population P_D evolve competitively over G = 50 generations, guided by the Mutation Survival Score (MSS) and Detector Robustness Score (DRS). MSS drops from 11.4% to 2.1% after training.

## Datasets

| Dataset | URL | Samples | Features | Attack Categories |
|---------|-----|---------|----------|-------------------|
| CIC-IDS2017 | https://www.unb.ca/cic/datasets/ids-2017.html | 2,830,743 | 80 | 7 |
| CSE-CIC-IDS2018 | https://www.unb.ca/cic/datasets/ids-2018.html | 16,233,002 | 80 | 14 |

Both datasets are generated by the Canadian Institute for Cybersecurity using CICFlowMeter. Download all CSV files and place them as follows:

```
data/
  CIC-IDS2017/
    raw/
      Monday-WorkingHours.pcap_ISCX.csv
      Tuesday-WorkingHours.pcap_ISCX.csv
      ...
  CSE-CIC-IDS2018/
    raw/
      02-14-2018.csv
      ...
```

## Installation

```bash
pip install -r requirements.txt
```

Tested on Python 3.10, CUDA 11.8. Two NVIDIA A100 80GB GPUs were used in the paper (training time: 6.2 hours).

---

## Usage

**Train:**
```bash
python train.py --seed 42
```

Run across all five seeds to reproduce paper means:
```bash
for seed in 42 123 456 789 1024; do python train.py --seed $seed; done
```

**Evaluate:**
```bash
python evaluate.py --ckpt checkpoints/mutashieldnet_best.pt
```

Add `--adv` for FGSM adversarial robustness evaluation:
```bash
python evaluate.py --adv
```

**Inference on a single sample:**
```bash
python inference.py --input my_flow.json
```

where `my_flow.json` is a JSON array of 80 CICFlowMeter feature values.
